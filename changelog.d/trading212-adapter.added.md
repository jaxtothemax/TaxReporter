- **Trading 212 exports**: TaxReporter can now read Trading 212 history exports (CSV) in each of the four column layouts Trading 212 has used since 2021. It recognizes the file by its contents, not its name, and reads purchases, sales, dividends with the tax withheld on them, and stock splits. Each date is taken in Slovenian time, so a trade late in the evening lands on the right day. Cash movements are set aside, and interest is flagged, since it belongs on a return the app does not build yet. Anything it cannot read with certainty stops the import with a clear reason instead of a guess. Examples are a transfer between brokers, a spin-off, a column it does not know, or a number in an unexpected format. The same rows in two overlapping exports are counted once.
