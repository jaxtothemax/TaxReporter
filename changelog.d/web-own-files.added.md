- **Your own files in the browser**: the web app now reads Trading 212 CSV and Interactive Brokers Flex Query XML exports on your device and prepares Doh-KDVP and Doh-Div from them, with the same engine as the command line, so the same files give the same XML. Files are read in a background worker that removes its network and storage functions before it reads anything. Each file shows its broker and the days it covers, or why it cannot be read, and two or more Trading 212 files bring the question of whether they are one account. The details step asks for each dividend payer's name, address and country, preset from the export where it can be and never looked up online; a payer still missing holds back only Doh-Div. Every finding is worded in Slovenian and English, nothing is uploaded, and the browser asks before the tab is closed while your files are loaded.
