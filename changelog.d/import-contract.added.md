- **Overlapping exports are checked against each other**: when two exports of one account cover the same days, TaxReporter compares what each of them recorded. A trade, dividend or withheld tax that one has and the other lacks stops the return, since one of the files is wrong or the two are not one account; an export that left out a whole kind, such as dividends, gets a warning. The same file given twice is read once. Trading 212 exports, which do not name their account, are taken as one account unless you pass `--accounts separate`; files taken for separate accounts that hold the same trades stop the return instead of counting them twice. Purchases made on the same day are matched in the order of the broker's timestamps, and a warning says where no timestamp could decide. No return is written while any row of an export is refused, and a return left in the folder by an earlier run is flagged as not matching. The command line writes returns readable only by you, never half a file. Findings that leave your screen, and the keys TaxReporter gives your trades, hold no file names, account numbers or order numbers.
