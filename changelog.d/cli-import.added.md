- **Command line**: `taxreporter <exports...> --year 2026 --tax-number <number> --out <folder>` now reads Trading 212 history exports and Interactive Brokers Activity Flex Query statements and writes the Doh-KDVP and Doh-Div files for eDavki into the folder you name. It prints what it read, the estimated tax, and every finding grouped by how serious it is. It exits with an error code while anything still blocks the return, so scripts can rely on it. Payer details for dividends come from a small JSON file (`--payers`), since brokers do not export them. Files that are no broker export are refused before any of their contents are read. Examples are a PDF, an old Excel file, or text that is not UTF-8. A run takes at most 100 files, of 256 MiB together: a file past that is measured, never read, and the run writes nothing. `--json` prints the same report for other tools to read.
