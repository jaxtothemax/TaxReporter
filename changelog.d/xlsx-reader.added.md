- **Excel workbooks (XLSX), read safely**: the command line can now open the XLSX files that eToro, XTB and Saxo export, with TaxReporter's own strict reader and no outside library. It reads only what a broker's workbook holds: the list of sheets, and the cells of a sheet when one is needed, each number exactly as the spreadsheet stored it, and each date in the workbook's own date system. A file that is not laid out as Excel lays one out, that holds formulas or macros, or that would unpack to more than 64 MiB is refused, with the reason and the sheet and cell where reading stopped. No broker's workbook is recognized yet: eToro's comes first, and until it does an XLSX export is opened, checked and reported as not recognized, and the web app does not take XLSX files.
